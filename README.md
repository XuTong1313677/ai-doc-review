#### 安装教程

1.  搭建python环境(Python 3.11.9)
2.  启动服务
pip install -r requirements.txt
python app.py
（备注：requirements.txt中安装你所需要的库）


#### 使用说明

调用api
传入文件id，可获取数据（如传入id为123456的文件）
http://localhost:5000/export/auditfile/123456

获取全部文件id与文件名
http://localhost:5000/api/info/list
